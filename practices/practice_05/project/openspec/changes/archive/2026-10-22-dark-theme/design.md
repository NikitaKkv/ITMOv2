# Design

## Context

WordBridge — это клиентское одностраничное веб-приложение без внешних npm-библиотек и сборщиков (Vanilla JS + HTML5 + CSS3). Вся визуальная стилизация сосредоточена в `src/styles.css`, а интерактивная логика — в `src/app.js`.

Базовые CSS-переменные для светлой темы уже определены в блоке `:root` (согласно спецификации Genesis в `docs/front.md`), однако во многих компонентах (`.top-nav`, `.dot-grid-bg`, карточках и чипах) цвета были заданы напрямую через hex/rgba.

Подробнее о мотивации и скоупе см. [proposal.md](file:///home/nikita/ITMO/ITMOv2/practices/practice_05/project/openspec/changes/dark-theme/proposal.md), о требованиях к поведению — [spec.md](file:///home/nikita/ITMO/ITMOv2/practices/practice_05/project/openspec/changes/dark-theme/specs/ui-theme/spec.md).

## Goals / Non-Goals

**Goals:**
- Обеспечить переключение темы через единый корневой атрибут `data-theme` на элементе `<html>`.
- Предотвратить мигание светлой темы (FOUC) за счёт раннего синхронного скрипта в `<head>`.
- Реализовать тёмную палитру в стиле Genesis с глубоким графитовым фоном (`#09090B`), карточками (`#18181B`) и сохранением фирменного индиго-акцента (`#6366F1`).
- Полностью адаптировать компоненты, теги (`.tag-*`), бейджи (`.showdown-badge`) и ховеры вторичных кнопок (`.btn-secondary:hover`), исключив появление светлых пятен.
- Реализовать двухпозиционный переключатель в панели навигации с правильной логикой иконок: Луна 🌙 при светлой теме, Солнце ☀️ при тёмной.
- Обеспечить персистентность в `localStorage` со строгой валидацией значений (только `'dark'` или `'light'`), автоопределением `prefers-color-scheme` и безопасным перехватом ошибок.

**Non-Goals:**
- Реализация сложного выпадающего меню с 3 опциями (Light / Dark / System).
- Добавление внешних пакетов иконок (все иконки — легковесный inline SVG).
- Переопределение или модификация игровой логики и правил победы в `src/app.js` и `tests/test_logic.py`.

## Decisions

### 1. Механизм переключения тем: селектор `[data-theme="dark"]` на корневом теге `<html>`
- **Выбор**: Использование CSS-атрибута `[data-theme="dark"]` на теге `<html>`.
- **Обоснование**: Переопределяет переменные на самом верхнем уровне каскада CSS, не конфликтует со служебными классами `<body>`, легко инспектируется в инструментах разработчика и тестируется.
- **Альтернативы**:
  - Использование только медиа-запроса `@media (prefers-color-scheme: dark)`: не позволяет пользователю принудительно выбрать тему вопреки системным настройкам.
  - Переключение класса `.dark-theme` на `<body>`: требует дополнительной проверки готовности DOM и менее семантично, чем `data-theme` на `<html>`.

### 2. Ранний синхронный скрипт в `<head>` для устранения FOUC
- **Выбор**: Вставка компактного синхронного инлайн-скрипта в начало `<head>` файла `src/index.html` перед внешними стилями:
  ```html
  <script>
    (function() {
      try {
        var theme = localStorage.getItem('wb_theme');
        if (theme !== 'dark' && theme !== 'light') {
          theme = (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches) ? 'dark' : 'light';
        }
        document.documentElement.setAttribute('data-theme', theme);
      } catch (e) {
        document.documentElement.setAttribute('data-theme', 'light');
      }
    })();
  </script>
  ```
- **Обоснование**: Выполняется блокирующе до первой визуальной компоновки страницы. Браузер сразу знает актуальный `data-theme` и рендерит интерфейс без мерцания белым фоном.

### 3. Палитра темы Genesis Dark и точечная адаптация компонентов
- **Выбор**: Графитовая шкала Genesis, гармонирующая с индиго:
  - `--background`: `#09090B` (вместо `#FAFAFA`)
  - `--surface`: `#18181B` (вместо `#FFFFFF`)
  - `--surface-subtle`: `#27272A` (для чипов, ховеров и второстепенных плашек)
  - `--text-primary`: `#FAFAFA` (вместо `#0A0A0A`)
  - `--text-secondary`: `#A1A1AA` (вместо `#6B6B6B`)
  - `--border`: `#27272A` (вместо `#E8E8EC`)
  - `--border-subtle`: `#3F3F46`
  - `--nav-bg`: `rgba(24, 24, 27, 0.85)` (вместо `rgba(255, 255, 255, 0.85)`)
  - `--dot-grid-color`: `rgba(255, 255, 255, 0.08)` (вместо `rgba(0, 0, 0, 0.07)`)
  - `--primary`: `#6366F1` (сохраняется для интерактивных элементов)
- **Точечные адаптации компонентов**:
  - `.btn-secondary:hover`: в тёмной теме фон переключается на `var(--surface-subtle)` (`#27272A`), рамка на `var(--border-subtle)` (`#3F3F46`), цвет текста `var(--text-primary)`.
  - `.tag-success`: полупрозрачный зеленый фон `rgba(16, 185, 129, 0.15)`, граница `rgba(16, 185, 129, 0.3)`, текст `#34D399`.
  - `.tag-primary`: полупрозрачный индиго фон `rgba(99, 102, 241, 0.15)`, граница `rgba(99, 102, 241, 0.3)`, текст `#A5B4FC`.
  - `.tag-neutral`: нейтральный тёмный фон `rgba(161, 161, 170, 0.15)`, граница `rgba(161, 161, 170, 0.3)`, текст `#D4D4D8`.
  - `.showdown-badge`: акцентный полупрозрачный фон `rgba(99, 102, 241, 0.2)`, граница `rgba(99, 102, 241, 0.35)`, текст `#A5B4FC`.

### 4. Модуль управления темой и валидация мусора в `src/app.js`
- **Выбор**: Функции `getStoredTheme()`, `setTheme(theme)`, `toggleTheme()`, `initTheme()`.
- **Строгая валидация**:
  ```javascript
  function getStoredTheme() {
    try {
      const val = localStorage.getItem('wb_theme');
      return (val === 'dark' || val === 'light') ? val : null;
    } catch {
      return null;
    }
  }
  ```
  Если сохранённое значение отсутствует, повреждено или содержит недопустимую строку, выполняется fallback на `window.matchMedia('(prefers-color-scheme: dark)')` или `'light'`.

### 5. Контрол в `src/index.html` и начальное состояние иконки
- **Выбор**: Кнопка `<button id="theme-toggle-btn" class="btn btn-secondary" type="button" aria-label="Переключить цветовую тему">` в контейнере `.nav-right`.
- **Отображение иконок**:
  - В разметке кнопки размещены две SVG-иконки: `.theme-icon-moon` (Луна) и `.theme-icon-sun` (Солнце).
  - В светлой теме (по умолчанию): отображается Луна 🌙 (призыв активировать тёмную тему), иконка Солнца скрыта (`display: none`).
  - В тёмной теме (`html[data-theme="dark"]`): отображается Солнце ☀️ (призыв активировать светлую тему), иконка Луны скрыта.

## Risks / Trade-offs

- **[Риск 1: Эффект «зебры» из-за пропущенных жестких цветов]**
  - *Митигация*: Семантизация стилей `.dot-grid-bg`, `.top-nav`, `.tag-*`, `.showdown-badge`, `.btn-secondary:hover` и контейнеров карточек.
- **[Риск 2: Мерцание светлой темы (FOUC) при первой отрисовке]**
  - *Митигация*: Вынесение раннего инлайн-скрипта в начало `<head>`, отрабатывающего до парсинга CSS.
- **[Риск 3: Поврежденные данные в `localStorage` или блокировка хранилища]**
  - *Митигация*: Строгая валидация `getStoredTheme()` и безопасное оборачивание всех вызовов `localStorage` в `try...catch`.

## Migration Plan

Изменение полностью обратно совместимо: при отсутствии атрибута `data-theme="dark"` проект использует существующие переменные `:root` (светлая тема). Никаких миграций данных или изменений структуры сохранений не требуется.
