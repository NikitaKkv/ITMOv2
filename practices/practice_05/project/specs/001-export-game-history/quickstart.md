# Quickstart & Validation Guide: Экспорт истории игры в JSON

**Feature**: `001-export-game-history` | **Date**: 2026-10-22

Данное руководство описывает сценарии сквозной валидации (end-to-end) функциональности экспорта истории игры WordBridge.

---

## 1. Подготовка и запуск окружения

### Предварительные требования
* Python 3.10+ (для запуска юнит-тестов логики)
* Node.js 18+ (для синтаксической проверки JS-файлов)
* Браузер (Chrome, Firefox, Safari или Edge)

### Команды запуска

1. **Запуск автоматических тестов (TDD):**
   ```bash
   bash .agents/skills/tdd/run_tests.sh
   ```
   *Ожидаемый результат:* Все тесты логики построения моста, судейства и экспорта завершаются со статусом `OK`.

2. **Запуск полного набора хуков и проверок:**
   ```bash
   bash scripts/check_all.sh
   ```
   *Ожидаемый результат:* Успешная валидация синтаксиса JavaScript и прохождение тестов.

3. **Запуск локального веб-сервера:**
   ```bash
   python3 -m http.server 8000 --directory src
   ```
   Приложение доступно по адресу `http://localhost:8000`.

## 2. Сценарии ручной проверки (Manual E2E)

### Сценарий 1: Экспорт полной истории после Solo и Duel раундов (US-1 / P1)
1. Открыть браузер на странице `http://localhost:8000`.
2. В режиме **«Одиночная игра»**:
   - Ввести промежуточные слова и замкнуть мост до целевого слова.
   - Убедиться, что появился победный баннер.
3. Переключиться на режим **«Дуэль (Hot-seat)»** (подрежим «Гонка»):
   - Завершить цепочку за Игрока 1.
   - Нажать «Передать ход Игроку 2».
   - Завершить цепочку за Игрока 2.
   - На экране Showdown подтвердить или оспорить цепочки.
4. В верхней панели навигации нажать кнопку **«Экспорт истории»** (иконка сохранения/скачивания):
   - *Ожидаемый результат:* Браузер скачивает файл `wordbridge-history-YYYY-MM-DD-HHmmss.json`.
   - Открыть скачанный файл: убедиться, что он содержит `schemaVersion: "1.0.0"`, `summary.totalRounds: 2`, и массив `rounds` содержит ровно 2 записи (один solo, один duel) со всеми полями согласно [data-model.md](data-model.md).

### Сценарий 2: Быстрый экспорт одного раунда с экрана Showdown (US-2 / P2)
1. Сыграть раунд в режиме «Дуэль».
2. На экране Showdown нажать кнопку **«Экспорт раунда в JSON»**.
   - *Ожидаемый результат:* Скачивается файл раунда, содержащий JSON только текущей партии со структурой объекта `GameRoundRecord`.

### Сценарий 3: Копирование структуры JSON в буфер обмена (US-3 / P3)
1. Нажать кнопку **«Копировать JSON»**.
2. Убедиться, что индикатор кнопки временно сменился на «Скопировано! ✓».
3. Открыть текстовый редактор и вставить содержимое (`Ctrl+V` / `Cmd+V`):
   - *Ожидаемый результат:* Вставляется валидный форматированный JSON, соответствующий контракту [contracts/export-schema.json](contracts/export-schema.json).

## 3. Валидация JSON через CLI

Сгенерированный файл экспорта можно проверить на соответствие схеме с помощью стандартной утилиты Python:

```bash
python3 -c '
import json
with open("wordbridge-history.json", "r", encoding="utf-8") as f:
    data = json.load(f)
assert data["schemaVersion"] == "1.0.0"
assert data["appName"] == "WordBridge"
assert "summary" in data
assert "rounds" in data
print("✓ JSON файл корректен и валиден!")
'
```
