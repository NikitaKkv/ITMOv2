## 1. Подготовка и запуск окружения

### Предварительные требования:
- Python 3.8+ (для запуска локального HTTP-сервера и автотестов)
- Любой современный веб-браузер (Google Chrome, Firefox, Safari или Edge)

### Шаг 1: Запуск локального сервера
В корневом каталоге проекта выполните команду:
```bash
python3 -m http.server 8000 --directory src
```
Сервер будет доступен по адресу: `http://localhost:8000`

### Шаг 2: Запуск юнит-тестов контракта и логики экспорта
```bash
python3 -m unittest tests/test_export.py
```
*Ожидаемый результат:* Все тесты формата данных, сериализации JSON и fallback-механизмов успешно проходят (OK).

## 2. Сценарии сквозной валидации (End-to-End Walkthrough)

### Сценарий 1: Проверка отображения кнопки вызова на экране Showdown
1. Откройте `http://localhost:8000` в браузере.
2. Выберите режим «Дуэль: Гонка» и пройдите раунд обоими игроками до экрана Showdown (либо в консоли разработчика переключите фазу в `showdown`).
3. **Проверка**: В блоке кнопок внизу экрана рядом с кнопками «Реванш» и «В соло-режим» отображается стилизованная кнопка `[📤 Экспорт результатов]`.

### Сценарий 2: Открытие модального окна и предварительный просмотр
1. Нажмите на кнопку `[📤 Экспорт результатов]`.
2. **Проверка**:
   - Появляется полупрозрачный затемненный оверлей с эффектом размытия фона.
   - Открывается центрированное модальное окно с заголовком «Итоги матча».
   - В поле предпросмотра отображается форматированный отчет с эмодзи, словами старта/цели, числом шагов и победителем.
   - Блок статуса находится в исходном состоянии: иконка `ℹ️`, надпись *«Выберите действие для экспорта»*.
   - Фокус ввода автоматически установлен на кнопку «Скопировать».

### Сценарий 3: Копирование в буфер обмена и проверка анимации статуса
1. Нажмите кнопку `[📋 Скопировать]`.
2. **Проверка**:
   - На доли секунды отображается спиннер и статус *«Копирование в буфер...»*, кнопки блокируются.
   - Статус переключается на неоново-зеленый бейдж: `[👍 Результаты скопированы в буфер!]`.
   - Вставьте текст из буфера (Ctrl+V) в любой текстовый редактор или консоль — текст совпадает с предпросмотром.
   - Через 3 секунды зеленый статус плавно возвращается в исходное нейтральное состояние `idle`.

### Сценарий 4: Скачивание отчета в формате JSON
1. Нажмите кнопку `[📁 Скачать JSON]`.
2. **Проверка**:
   - Браузер инициирует загрузку файла с именем вида `wordbridge-match-YYYY-MM-DD-HHmmss.json`.
   - Статус отображает: `[📁 Файл успешно сохранён!]`.
   - Откройте скачанный файл: структура строго соответствует контракту `MatchSummaryPayload` (`schemaVersion: "1.0.0"`).

### Сценарий 5: Закрытие модального окна и доступность (a11y)
1. Нажмите клавишу `Escape` на клавиатуре.
2. **Проверка**:
   - Модальное окно плавно закрывается.
   - Фокус клавиатуры возвращается на кнопку вызова `[📤 Экспорт результатов]`.
3. Повторно откройте окно и кликните за пределами карточки модалки (на темный фон).
4. **Проверка**: Окно корректно закрывается без ошибок в консоли.
