# docs/HANDOFF.md — Передача контекста проекта (Practice 04)

## 1. Текущее состояние
В проекте **WordBridge** полностью реализованы и объединены две ключевые фичи:
* **Фича A (Chain Builder):** Интерактивное построение цепочки ассоциаций между стартовым и целевым словом с валидацией дубликатов, счетчиком шагов, отменой хода (Undo) и автоматическим замыканием с победным звуком.
* **Фича B (Hot-seat Duel & Showdown):** Дуэль для двух игроков на одном устройстве. Включает 2 режима («Гонка» на одной паре и «Вызов» с загадыванием слов сопернику), защитный экран передачи хода («Не подглядывай!») и финальный экран сопоставления путей (Showdown) со счетчиком шагов и кнопками взаимного судейства («Одобрить мост 👍» / «Оспорить 🤨»).

Ветка `practice-04-b` успешно смерджена в `practice4` через `--ff-only` после независимого аудита субагентом (@explore / Code Reviewer).

---

## 2. Ключевые источники и структура
* `AGENTS.md` — главный манифест агента: правила, стек, запуск и проверки.
* `docs/front.md` — дизайн-система Genesis (цвета `#6366F1`, `#0A0A0A`, сетка 4px, радиусы 12px/6px).
* `src/` — исходный код игры (`index.html`, `styles.css`, `app.js`, `words.js`, `audio.js`).
* `tests/test_logic.py` — набор из 8 TDD-тестов бизнес-логики.
* `.agents/skills/` — подключенные навыки (`tdd`, `web-code-style`, `python-code-style`).
* `.agents/hooks.json` — хук жизненного цикла агента (`PostToolUse`).
* `mcp_config.json` — конфигурация MCP-серверов.

---

## 3. Команды проверки и запуска
* **Запуск единой проверки (синтаксис + тесты):**
  ```bash
  ./scripts/check_all.sh
  ```
* **Запуск игры в браузере:**
  ```bash
  python3 -m http.server 8000 --directory src
  ```
  URL: `http://localhost:8000`

---

## 4. Ограничения и правила
* **Zero-dependency:** только нативный JS/CSS/HTML без сторонних npm-пакетов и бандлеров.
* **Web Audio API:** воспроизведение звуков через нативный синтез осцилляторов без внешних MP3-файлов.
* **Детерминированность:** любой коммит или правка валидируются через `./scripts/check_all.sh`.
