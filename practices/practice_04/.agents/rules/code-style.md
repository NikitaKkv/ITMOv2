# .agents/rules/code-style.md — Стандарты кода

Эти правила обязательны для соблюдения всеми AI-агентами и разработчиками в данном репозитории.

---

## 1. JavaScript (ES6+)

1. **Модульность и чистые функции:**
   * Не захламлять глобальный `window`.
   * Разделять ответственность: аудио (`audio.js`) не должно напрямую манипулировать DOM элементами таймера. Все взаимодействия происходят через функции/методы или события.
2. **Переменные:**
   * Строго `const` по умолчанию.
   * `let` только для изменяемых значений (например, счётчик секунд таймера).
   * Использование `var` запрещено.
3. **Именование:**
   * `camelCase` для функций и переменных (`startTimer`, `audioEngine`).
   * `UPPER_SNAKE_CASE` для констант конфигурации (`DEFAULT_FOCUS_MINUTES = 25`).
   * Осмысленные имена обработчиков событий: `handlePlayClick`, `handleVolumeChange`.

---

## 2. Web Audio API

1. **Ленивая активация AudioContext:**
   * Браузеры блокируют автовоспроизведение звука до первого взаимодействия пользователя.
   * `new (window.AudioContext || window.webkitAudioContext)()` создается или переводится в `.resume()` только по первому клику/сдвигу слайдера.
2. **Очистка ресурсов:**
   * При остановке или затухании звуков плавно изменять `.gain.setTargetAtTime(0, audioCtx.currentTime, 0.05)` во избежание щелчков («audio pops/clicks»).
3. **Безопасность громкости:**
   * Никогда не выставлять суммарный `gain` выше `1.0` во избежание цифрового клиппинга (хрипа динамиков).

---

## 3. CSS и верстка

1. **Только классы и кастомные свойства:**
   * Не использовать inline-стили `style="..."` в HTML.
   * Все цвета брать исключительно из CSS-переменных (`var(--bg-color)`, `var(--accent-amber)`).
2. **Анимации:**
   * Для анимаций использовать только производительные свойства: `transform`, `opacity`, `stroke-dashoffset`.
   * Избегать анимирования `width`, `height`, `top`, `left`.
